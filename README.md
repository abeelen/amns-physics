# 🌐 Optique Géométrique – Application Streamlit

Bienvenue dans cette **application interactive** développée dans le cadre d’un cours de mise à niveau universitaire en **optique géométrique**.  
Elle permet de **visualiser**, **manipuler** et **comprendre** la formation des images à travers différents systèmes optiques.

## 🎯 Objectifs pédagogiques
- 🔄 Revoir les notions de base en optique géométrique  
- 📏 Illustrer la réflexion et la réfraction de la lumière  
- 🖱️ Manipuler des paramètres et observer leur effet en direct  


---

## 📑 Modules disponibles
- 🪞 **Miroir sphérique** : étude des miroirs concaves et convexes  
- 📐 **Dioptre plan** : réfraction à travers une surface plane  
- 🔎 **Lentille mince** : lentilles convergentes et divergentes  

---

## 🚀 Installation et exécution

### 1️⃣ Cloner le dépôt

```bash
git clone https://gitlab.lam.fr/abeelen/geometrical-optics.git
cd geometrical-optics
```

### 2️⃣ Lancer l’application avec [uv](https://docs.astral.sh/uv/)

```bash
uv run streamlit run app.py
```

Dépendances principales
* [streamlit](https://streamlit.io/)
* [numpy](https://numpy.org/)
* [matplotlib](https://matplotlib.org/)
